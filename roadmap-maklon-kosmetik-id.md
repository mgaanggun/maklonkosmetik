Karena profil audiens kompetitor belum dapat diperiksa kembali, gunakan segmentasi berikut sebagai **hipotesis awal**. Validasi melalui percakapan pelanggan dan data keyword.

Domain memuat istilah “maklon kosmetik”, tetapi kualitas dan relevansi setiap halaman tetap perlu dibangun.

### AEO

Gunakan pola jawaban:

1. Jawaban langsung.
2. Kondisi yang berlaku.
3. Penjelasan.
4. Tautan atau langkah berikutnya.

Contoh pertanyaan:

> Apakah saya harus sudah mempunyai formula sebelum konsultasi?

Draf jawaban untuk disesuaikan dengan layanan nyata:

> Kebutuhan formula awal bergantung pada model layanan yang dipilih. Pada konsultasi, calon pelanggan perlu menjelaskan konsep produk dan kebutuhan pengembangan. Tim kemudian meninjau informasi serta pekerjaan yang diperlukan sesuai layanan yang tersedia.

Jangan memaksa setiap paragraf menjadi potongan jawaban AI. Format dipilih agar manusia mudah memahami isi.

### GEO

Fokus:

- Nama merek konsisten.
- Hubungan badan usaha jelas.
- Layanan terkonfirmasi.
- Alamat dan fungsi lokasi benar.
- Dokumen memiliki pemegang serta ruang lingkup.
- Konten mempunyai penanggung jawab.
- Pengalaman disertai bukti.
- Sumber eksternal digunakan ketika relevan.

**GEO pada rencana ini bukan kewajiban membuat halaman atau file tambahan untuk AI.** Panduan Google menyatakan bahwa tidak ada schema khusus untuk pencarian generatif, dan `llms.txt` tidak digunakan untuk meningkatkan visibilitas Google Search. | CONTENT-05 | Panduan persiapan konsultasi | P2 | Pertanyaan sales | Membantu pengiriman kebutuhan |

## 19. Pengukuran dan evaluasi

### Event awal

| Event | Pemicu |
|---|---|
| `click_whatsapp` | Tombol WhatsApp diklik |
| `form_start` | Pengguna mulai mengisi |
| `form_submit_success` | Backend mengonfirmasi pengiriman diterima |
| `download_brief` | Aset brief diunduh |
| `click_consultation` | CTA konsultasi diklik |

Jangan mengirim nama, nomor telepon, email, atau isi kebutuhan pelanggan ke analytics.

### Pipeline lead

1. Permintaan diterima.
2. Belum ditinjau.
3. Dalam tindak lanjut.
4. Sesuai.
5. Perlu edukasi/perencanaan.
6. Tidak sesuai.
7. Penawaran.
8. Proyek berjalan.
9. Ditunda atau tidak dilanjutkan.

Simpan alasan ketidaksesuaian: kategori, jumlah, anggaran, waktu, atau cakupan layanan.

### KPI setiap fase

| Fase | KPI utama |
|---|---|
| Pengembangan | Fakta disetujui, halaman siap, fungsi lulus |
| Awal peluncuran | Akses, indexing, kueri relevan, permintaan diterima |
| Bulan 4–6 | Lead sesuai, informasi yang membantu sales, penawaran |
| Bulan 7–12 | Proyek per cohort, manfaat per kategori, biaya per lead sesuai |

Target trafik dan lead ditetapkan setelah baseline serta kapasitas sales diketahui.

### Evaluasi AEO/GEO

Pisahkan:

- Merek disebut.
- URL dikutip.
- Informasi akurat.
- Referral tercatat.
- Pelanggan menyatakan menemukan bisnis melalui AI.

Catat pertanyaan persis, platform, mode, bahasa, tanggal, kondisi sesi, jawaban, dan URL sumber. Hasil merupakan sampel pengujian.

### Ritme evaluasi

| Frekuensi | Pemeriksaan |
|---|---|
| Mingguan | Formulir, lead, hambatan sales, pekerjaan yang tertahan |
| Bulanan | Kueri, halaman, kualitas lead, konten, log AEO/GEO |
| Setiap 90 hari | Cakupan layanan, manfaat bisnis, prioritas berikutnya |
| Saat ketentuan berubah | Biaya, MOQ, jadwal, kontak, dokumen, dan klaim |

## 20. Checklist peluncuran

### Identitas dan informasi

- [ ] Nama Maklon Kosmetik ID konsisten.
- [ ] Nama badan usaha benar.
- [ ] Hubungan dengan fasilitas atau mitra dijelaskan.
- [ ] Kategori yang ditampilkan tersedia.
- [ ] Biaya, MOQ, dan jadwal telah diperiksa.
- [ ] Tidak ada placeholder yang tertinggal.
- [ ] Dokumentasi memiliki konteks dan hak penggunaan.
- [ ] Klaim sesuai bukti.

### Halaman dan navigasi

- [ ] Homepage mengarahkan tiga jalur pengunjung.
- [ ] Halaman layanan menjelaskan cakupan.
- [ ] Halaman kategori memiliki isi khusus.
- [ ] Proses, biaya, dan MOQ mudah ditemukan.
- [ ] Tidak ada menu menuju halaman kosong.
- [ ] Semua halaman mempunyai internal link.
- [ ] Breadcrumb sesuai hierarki.
- [ ] Mobile dapat digunakan.

- [ ] HTTPS dan domain utama konsisten.

- [ ] Canonical benar.
- [ ] Halaman publik tidak terkena `noindex` tanpa sengaja.
- [ ] Sitemap sesuai URL publik.
- [ ] Tidak ada tautan rusak yang menghambat jalur utama.
- [ ] Konten penting dapat dirender.
- [ ] Gambar dan komponen tidak menggeser layout secara berlebihan.
- [ ] Staging tetap terbatas.
- [ ] Backup dan pemulihan tersedia.

- [ ] Formulir berhasil diterima backend.
- [ ] Data tersimpan.
- [ ] Notifikasi sampai.
- [ ] Konfirmasi kepada pengunjung benar.

- [ ] CRM mempunyai pemilik.

- [ ] Perubahan dicatat.
- [ ] Pemilik setiap halaman ditetapkan.
- [ ] Pemeriksaan sesudah peluncuran dijadwalkan.
- [ ] Pekerjaan berikutnya dipilih berdasarkan bukti.
